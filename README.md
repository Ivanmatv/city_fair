# “City fair”
As part of the fair, each seller can register for several retail locations in different areas of the city. The seller exists independently and can leave the fair at any time.

## Structure
 - main.py - file lunches of the application 'City fair'
 - retail_outlet.py - describe retail outlet structure
 - seller.py - describe seller profile

## Installation

1) Clone repository
```
git clone https://github.com/Ivanmatv/city_fair.git
```
2) Change directory
```
cd city_fair
```

## Usage 

Launch the application
```
python main.py
```
